# 边界条件

本文档记录 Stokes 求解器当前采用的边界条件及其离散方式。温度边界见 `src/boundary.cu`。

## 速度：全自由滑移

二维不可压缩 Stokes 求解器对速度采用**全自由滑移**边界：法向速度为零、切向应力为零（即切向速度的法向导数为零）。

在 MAC 交错网格上，法向速度分量直接落在边界面上，切向分量需要 ghost 单元实现零法向导数：

| 边界 | 法向分量 | 切向分量离散 |
|---|---|---|
| 左右壁 `i=0, nx` | `u=0`（Dirichlet） | `v` 在 `i=0` 与 `i=nx-1` 用镜像 `v(-1)=v(0)` 等，退化为单侧差分 |
| 上下壁 `j=0, ny` | `v=0`（Dirichlet） | `u` 在 `j=0` 与 `j=ny-1` 用镜像 `u(j=-1)=u(j=0)` 等，退化为单侧差分 |

常黏度下切向应力 `η(∂u_t/∂n + ∂u_n/∂t)` 中，`u_n=0` 沿边界使 `∂u_n/∂t=0`，故自由滑移等价于 `∂u_t/∂n=0`。

## 压力：零均值规范

全自由滑移下压力无 Dirichlet 边界，仅确定到任意常数。求解器在每次伪瞬态步后去除压力均值，固定规范（`subtract_mean_pressure`）。

## 未决事项

进入热对流耦合（阶段 3）前，需确认：

- 是否引入非均匀黏度，以及此时切向应力边界是否仍简化为 `∂u_t/∂n=0`。
- 顶底是否在自由滑移之外补充岩石圈/刚性板块约束。
