# 开发路线图

本路线图将“数值正确性”放在“GPU 性能优化”之前。每一阶段完成后都应保留对应基准的参数、输出和 Git commit ID。

## 阶段 0：已验证的温度模块骨架

- 使用 CMake 和 CUDA 完成构建。
- 验证设备内存分配与 CUDA 错误报告。
- 将 GPU 单步扩散结果与 CPU 参考结果逐元素比较。
- 使用上下固定温度、左右绝热的边界条件。

## 阶段 1：温度平流-扩散

- 已实现单元中心温度平流 kernel。
- 已采用一阶迎风格式，并在输出步计算显式 CFL。
- 已增加 CPU/GPU 对照测试和 CSV/PPM 温度场快照输出。

## 阶段 2：常黏度 Stokes 原型

- 已固化 MAC 网格索引，并通过散度/压力梯度的线性解析场测试。
- 已确定速度边界条件为全自由滑移，离散约定见 docs/边界条件.md。
- 已实现伪瞬态动量方程和连续性方程更新，并去除压力平均值。
- 已通过离散流函数制造解验证求解器收敛到机器精度（tests/test_stokes.cpp）。
- 待办：显式输出动量残差、散度残差作为独立诊断量。

## 阶段 3：热对流耦合

- 由温度计算浮力。
- 在每个物理时间步内先使 Stokes 迭代收敛，再推进温度。
- 使用 Rayleigh-Benard 基准算例验证 Nusselt 数和流场结构。

## 阶段 4：性能优化与非线性流变

- 分析 kernel 时间、主机设备数据传输和归约操作。
- 加入有上下限的温度相关黏度和 Picard 外迭代。
- 只有伪瞬态基准已经验证且性能不足时，才引入多重网格。
