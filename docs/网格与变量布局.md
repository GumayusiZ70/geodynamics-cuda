# 网格与变量布局

二维不可压缩 Stokes 方程不能把压力和两个速度分量都放在同一位置。项目采用 MAC 交错网格：压力位于单元中心，两个速度分量位于不同方向的单元面。这样离散散度和压力梯度天然配对，可避免压力棋盘格振荡。

| 变量 | 物理位置 | 数组尺寸 | 一维索引 |
|---|---|---|---|
| `T` | 单元中心 | `[ny][nx]` | `j * nx + i` |
| `p` | 单元中心 | `[ny][nx]` | `j * nx + i` |
| `eta` | 单元中心 | `[ny][nx]` | `j * nx + i` |
| `u` | x 方向速度，竖直单元面 | `[ny][nx+1]` | `j * (nx+1) + i` |
| `v` | y 方向速度，水平单元面 | `[ny+1][nx]` | `j * nx + i` |

## 已实现离散算子

在压力单元 `(i,j)`，离散散度为：

\[
(\nabla\cdot \mathbf{u})_{i,j}
= \frac{u_{i+1,j}-u_{i,j}}{\Delta x}
+ \frac{v_{i,j+1}-v_{i,j}}{\Delta y}.
\]

在内部速度面，离散压力梯度为：

\[
(\partial_x p)_{i,j}
= \frac{p_{i,j}-p_{i-1,j}}{\Delta x},
\qquad
(\partial_y p)_{i,j}
= \frac{p_{i,j}-p_{i,j-1}}{\Delta y}.
\]

当前压力梯度在外边界速度面暂设为零。这只是“算子布局验证”的临时约定；进入 Stokes 阶段后，必须按无滑移或自由滑移边界的物理含义重新定义速度、压力和黏性应力边界。

## 当前验证

`tests/test_mac_grid.cpp` 使用两个线性解析场：

| 输入 | 理论结果 | 验证目的 |
|---|---|---|
| `u=x`、`v=2y` | `div(u)=3` | 检查两个速度数组的面位置与散度符号。 |
| `p=3x-2y+5` | `dp/dx=3`、`dp/dy=-2` | 检查压力梯度方向、索引和边界面处理。 |
